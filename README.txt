BLOCK TRACKER — iPhone setup

This is a Progressive Web App (PWA).

To use it on an iPhone:
1. Host this folder on any static web host (GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.).
2. Open the hosted URL in Safari.
3. Tap Share.
4. Tap Add to Home Screen.
5. Launch Gym Tracker from the Home Screen.

Data is stored locally in the browser on that device.
Current version includes:
- You / Her profiles
- Weeks 1–6
- Shared-workout labels
- Set-by-set weight / reps / RIR logging
- Previous-week performance display
- Exercise demo links
- Intensity-technique prompts by week
- Her exercise Why + Goal notes
- Workout history
- Offline caching after the first load
- Block-ready architecture for future six-week programs

Important: opening index.html directly from the Files app is not enough for full PWA/offline behavior.
The folder needs to be served from a web host.
